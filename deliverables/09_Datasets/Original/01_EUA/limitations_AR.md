# القيود العلمية والعملية

- ليست trace تطبيق IoT/MEC أو workload تفريغ؛ لا وصول مهام أو حجم أو CPU أو deadlines أو قرارات offloading مرصودة.
- إسناد IP تقريبي وليس GPS لمستخدم فعلي؛ بعض المواقع اصطناعية؛ البيانات ثابتة مكانيًا.
- لا مقاييس latency أو bandwidth أو طاقة أو CPU/ذاكرة؛ تغطية الخلايا والسعات تجريبية في الورقة.
- MIT لا يحسم شروط البيانات الخارجية؛ توثيق فترة معظم الملفات غير متحقق.
