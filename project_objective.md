# Project Objective

## Research Title
Adaptive AI-Based Task Offloading in IoT
Edge-Cloud Networks Under Dynamic Conditions

## Problem Statement
Static task-offloading policies may not perform
well under changing network conditions, task
sizes, and edge resource utilization.

## Main Objective
Develop and evaluate an AI-based adaptive policy
that selects Local, Edge, or Cloud execution
according to the current system state.

## Evaluation Metrics
1. Average End-to-End Latency
2. Deadline Violation Rate
3. Edge and Cloud Resource Utilization
4. Task Offloading Distribution

## Baseline Policies
- Local-only
- Edge-only
- Cloud-only
- Adaptive AI Policy
