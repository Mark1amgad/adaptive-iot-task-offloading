# Ayoub — Simulator Input Data

`iFogSim_Melbourne_Mobility/` contains the dataset files copied from the external iFogSim workspace:

- `edgeResources-melbCBD.csv` — edge resource definitions.
- `usersLocation-melbCBD_1.csv` and five `random_usersLocation-melbCBD_*.csv` files — user-location/mobility inputs.
- `config.properties` — dataset configuration.
- `ResourceLocation.PNG` and `User1Mobility.PNG` — visual references.

These are simulator mobility/resource inputs, not measured task-offloading outcomes. The original external iFogSim worktree remains unchanged.
