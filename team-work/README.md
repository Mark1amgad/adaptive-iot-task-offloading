# Team Workspaces

This directory is for temporary work, prototypes, notes, and draft files submitted for review. It is not the final source of truth for the project.

## Workflow
1. Work on your own Git branch.
2. Put draft work in your named folder here when it is useful for review.
3. Open a Pull Request and describe what changed, how to test it, and what remains incomplete.
4. After approval, integrate accepted code into the appropriate project directory (for example `simulator/`, `rl-agent/`, or `integration/`).

Do not upload secrets, credentials, private data, or fabricated experimental results.
