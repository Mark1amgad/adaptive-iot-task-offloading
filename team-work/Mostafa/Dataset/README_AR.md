# حزمة بحث مجموعات بيانات IoT وEdge-Cloud

هذه الحزمة توثق ثماني مجموعات بيانات وتفصل بين المقاس والمشتق والمحاكى. لم تُنزّل الملفات الضخمة دون داعٍ، وأي ملف لم يُفحص فعليًا موسوم بذلك. التقرير الرئيس هو `DATASET_RESEARCH_REPORT_AR.pdf`.

## ما نُزّل وفُحص

- EUA: ثلاثة CSV صغيرة/متوسطة، وفُحصت الرؤوس والعينات وعدد الأسطر.
- Google Cluster Data: خمسة ملفات schema JSON؛ لم تُقرأ صفوف الأثر.
- UCI Image Recognition MEC: الأرشيف الرسمي، PDF الوصف، وأربعة CSV؛ 1000 صف لكل ملف.

## ما لم يُنزّل

ToN_IoT وCICIoT2023 وUNSW-IoTraffic وBot-IoT وUNSW-NB15 لم تُنزّل بياناتها الأصلية الكاملة؛ بعض المصادر تطلب نموذجًا/تسجيلًا، وبعض الملفات ضخمة أو أعادت 403. توجد تعليمات وروابط المصدر في مجلد كل مجموعة.

## قاعدة الأمانة

لا تُعامل حركة الشبكة كمهام حوسبة، ولا CPU المضيف كمتطلب CPU لمهمة، ولا `Execution Time` كـnetwork delay منفصل.
