# Shared Workspace

This directory is the team-wide library. Add approved or broadly useful
material here; keep personal drafts in `team-work/`.

| Area | Purpose |
| --- | --- |
| `Research/` | Approved journals, comparison papers, literature review, and paper extractions |
| `Datasets/` | Inventory, raw/processed data, schemas, and provenance |
| `Project_Documentation/` | Objective, architecture, decisions, and meeting notes |
| `Final_Deliverables/` | Approved final documents and release-ready summaries |

Do not classify papers, datasets, or results as approved without recording the
source, owner, status, and relevant evidence.
