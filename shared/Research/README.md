# Shared Research

`Approved_Papers/` is reserved for verified 2025-2026 journal references from
IEEE Xplore, SpringerLink, or ScienceDirect. `Comparison_Papers/` is for
comparison-only sources, including conference papers such as the ICC 2026 base
paper. Extraction tables belong in `Paper_Extractions/`; shared synthesis and
gap analysis belong in `Literature_Review/`.
